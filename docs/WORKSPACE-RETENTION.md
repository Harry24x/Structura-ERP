# Workspace retention — 29 October 2026

## English

The browser saves the current process, version history, edited description, pending change command and clarification answers. Reloading restores these fields without applying them or calling AI. Older saved workspaces remain supported. Language and diagram direction are separate preferences.

“Saved in this browser” appears only after a successful browser write. If storage is blocked or full, the status says “Not saved in this browser”. Keep the tab open and export Markdown to retain the process and pending text. JSON exports retain the process, without pending text. Browser storage is local and can be cleared; it is not a shared backup.

## Eesti

Brauser salvestab praeguse protsessi, versiooniajaloo, muudetud kirjelduse, pooleli muudatuskäsu ja täpsustuste vastused. Lehe värskendamine taastab need väljad neid rakendamata ega kasuta AI-d. Varasemad salvestused on endiselt toetatud. Keel ja diagrammi suund on eraldi eelistused.

„Salvestatud selles brauseris” kuvatakse alles pärast õnnestunud salvestamist. Kui salvestamine on blokeeritud või ruum täis, näitab olek „Selles brauseris salvestamata”. Hoia vaheleht avatuna ja ekspordi Markdown, et säilitada protsess koos pooleli tekstidega. JSON-eksport sisaldab protsessi ilma pooleli tekstideta. Brauseri andmed on kohalikud ja võivad kustuda; see ei ole jagatud varukoopia.

## Français

Le navigateur enregistre le processus, son historique, la description modifiée, la demande de modification et les réponses de clarification en attente. Le rechargement restaure ces champs sans les appliquer ni appeler l’IA. Les anciens espaces enregistrés restent compatibles. La langue et le sens du diagramme sont des préférences séparées.

« Enregistré dans ce navigateur » s’affiche après une écriture réussie. Si le stockage est bloqué ou plein, l’état indique « Non enregistré dans ce navigateur ». Gardez l’onglet ouvert et exportez en Markdown pour conserver le processus et les textes en attente. L’export JSON conserve le processus seul. Le stockage local peut être effacé et ne constitue pas une sauvegarde partagée.

## Deutsch

Der Browser speichert den Prozess, den Versionsverlauf, die bearbeitete Beschreibung, den ausstehenden Änderungswunsch und Klärungsantworten. Beim Neuladen werden diese Felder wiederhergestellt, ohne sie anzuwenden oder KI aufzurufen. Ältere gespeicherte Arbeitsbereiche bleiben kompatibel. Sprache und Diagrammrichtung sind separate Einstellungen.

„In diesem Browser gespeichert“ erscheint erst nach erfolgreichem Speichern. Bei gesperrtem oder vollem Speicher steht dort „In diesem Browser nicht gespeichert“. Lassen Sie den Tab geöffnet und exportieren Sie Markdown, um den Prozess und ausstehende Texte zu sichern. JSON enthält nur den Prozess. Lokale Browserdaten können gelöscht werden und sind keine gemeinsame Sicherung.
